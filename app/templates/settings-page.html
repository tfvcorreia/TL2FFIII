❓ Need Help?

Getting Your Firefly III Token:

  1. Open Firefly III in your browser
  2. Go to Options → Profile → OAuth
  3. Scroll to Personal Access Tokens
  4. Click Create New Token
  5. Give it a name like "TrueLayer Integration"
  6. Click Create
  7. Copy the token (you'll only see it once!)
  8. Paste it above

Firefly III URL Examples:

  • http://firefly:8080 - If running on same Docker network
  • http://192.168.1.100:8080 - If on same machine but different network
  • https://firefly.example.com - If using a domain with SSL
