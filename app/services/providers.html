How to Get a Refresh Token

  1. Log in to the TrueLayer Console
  2. Create or select your application
  3. Use the "Auth Flow" tool to generate an access link
  4. Complete the authentication flow for your bank
  5. Copy the refresh_token from the response
  6. Add it here using the form above
💡 Tip: Refresh tokens typically last for 90 days and are automatically renewed during sync operations. Make sure to set up automatic syncing to keep your tokens active!
